# API reference

_Generated by `node scripts/gen-dev-docs.mjs` by scanning the route handlers (611 routes). Paths are relative to `http://127.0.0.1:4747`. The server only listens on this computer (127.0.0.1); nothing here is reachable from the internet._

Conventions: JSON in, JSON out (`content-type: application/json`). Errors come back as `{ "error": "…" }` with a 4xx/5xx status. Live updates are pushed over Server-Sent Events at `GET /api/events` (see [Architecture](architecture.md#live-updates-server-sent-events)). `:id`/`:name` are path parameters.
